How to Join

1

Open Minecraft: Java Edition

Launch the Minecraft Java launcher and click "Play".

2

Go to Multiplayer

From the main menu, select "Multiplayer".

3

Add Server

Click "Add Server" at the bottom of the server list.

4

Enter the Server Address

Type mc.playburgersmp.net into the "Server Address" box.

5

Save and Join

Click "Done", then double-click BurgerSMP in your server list to connect!

1

Open Minecraft: Bedrock Edition

Launch Minecraft on your console, mobile, or Windows device.

2

Go to Servers Tab

From the main menu, select "Servers".

3

Scroll to Add Server

Scroll to the bottom and select "Add Server".

4

Enter Server Details

Server Name: BurgerSMP
Server Address: mc.playburgersmp.net
Port: 19132 (default Bedrock port)

5

Save and Join

Tap "Save", then select BurgerSMP from your server list to connect!
